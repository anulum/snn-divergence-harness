# Validation status

The repository foundation is under construction. The current documentation source builds with strict MkDocs validation, and the current source cohort passes native REUSE licence checking. These checks do not qualify repository-wide validation, a model driver, numerical comparison, statistical power, an installed domain package or a benchmark.

The available local commands are make metadata, make docs and make licence. The metadata command checks its complete source-selected descriptor/schema/lock scope; it does not grant domain acceptance. The other two commands invoke the project environment’s actual documentation renderer and source-licence checker respectively. The documentation build covers docs/ and excludes docs/internal/. Root Markdown links are checked separately; this is not a claim that every future product page or API is rendered.

Metadata is the first implemented project-owned control. Its dedicated tests exercise the real API and subprocess command. Source provenance, workflow policy, complete dependency alignment, documentation inspection, inventory and orchestration still require their complete owning implementations, tests and current evidence. There is no preflight success to inherit from another repository.

Later domain validation must exercise real subject entry points and independently constructed references across every maintained lane. Exact source populations, supported ports, nested outputs, reset and timing semantics remain explicit. Incomplete output, missing references or unestablished joint power cannot become accepted equivalence.

Coverage will enrol every maintained source path from its first implementation. Statement or branch percentages apply only to their reported source cohort and never establish numerical correctness by themselves.
