# Repository boundary

Status: design recorded; repository implementation in progress.

SNN Divergence Harness is a standalone comparison and replay tool. It consumes actual model execution surfaces rather than moving model equations into this repository. It consumes the installed Evidence Manifest Toolkit for shared evidence operations rather than maintaining a second implementation.

The boundary preserves three comparison lanes, five selected methods, four public operations and the complete seven-framework driver scope. A portable file or a passing local shape check does not qualify a driver, numerical method or downstream consumer.

Domain implementations enrol public API, native documentation, strict checks, tests, installation and affected counterpart benchmarks in their complete implementation change. Initial repository material declares no runtime capability or qualified schema. The parent model repository's eventual extraction does not grant this tool new source ownership.

See [architecture](../ARCHITECTURE.md).
